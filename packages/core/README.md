# @declaragent/core

Runtime core for [Declaragent](https://declaragent.dev) — the
declarative, git-versioned AI agent platform.

Ships the engine loop, built-in tools, permission gate, session
persistence, event bus + dispatcher, multi-tenant primitives, agent-RPC
envelope + configuration, and the v1.2 fleet manifest loader.

## Install

```bash
npm install @declaragent/core
# or: bun add @declaragent/core
```
