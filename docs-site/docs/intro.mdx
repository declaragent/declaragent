# Declaragent

A **declarative, git-versioned AI agent platform**. An agent is a stable runtime core plus a declarative `agent.yaml` that lives in your repo.

## Where to go next

- **[Reference →](/reference)** — the `agent.yaml` schema, CLI verbs, env vars, provider matrix, extension registry.
- **[Cookbook →](/cookbook)** — walkthroughs for each template and cross-cutting recipes (deploy, rotate a secret, run two tenants).
- **[Troubleshooting →](/troubleshooting)** — error-code reference, install + deploy flowcharts, runbook index.
