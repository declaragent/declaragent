# `concierge` template

Minimal Slack Q&A bot via Socket Mode. One skill (`concierge.md`) uses the provider-default `Read` / `Glob` / `Grep` tools to answer questions about the local repo. No webhook — works on any laptop behind NAT.

## Scaffold

```bash
declaragent init --template concierge --provider anthropic
```

Files produced:

```
./
├── agent.yaml
├── skills/concierge.md
├── channels.yaml            # Slack Socket Mode config
├── .env.example
└── README.md
```

See the canonical starter at [`templates/concierge/`](https://github.com/declaragent/declaragent/tree/main/templates/concierge) — the wizard unpacks that directory verbatim.

## Configure

1. Create a Slack app with Socket Mode enabled.
2. Grant `app_mentions:read`, `chat:write`, `im:history`, `reactions:write`.
3. Copy the bot token + app-level token into `.env` (see `.env.example`).

## Run locally

```bash
declaragent up -d    # bind Slack channel + event-sources, detach to the background
declaragent ps       # confirm the concierge is bound
declaragent logs -f  # watch events fire in real time
```

Mention the bot in a channel — the agent greets, reads the repo, and replies in-thread. `declaragent down` stops the agent when you're finished.

If you prefer a foreground REPL session instead of `up -d`:

```bash
declaragent up       # foreground; Ctrl-C to stop
```

## Key points

- `temperature: 0` keeps Q&A answers reproducible.
- Tools are restricted to `Read` / `Glob` / `Grep` — no shell, no outbound HTTP.
- The `eyes` emoji reaction fires immediately so senders know the agent saw the message.
